# 04 · 半调艺术风「炫技」升级说明（Art Flair）

> 在 Art Design Pro 令牌层（见 `03-ArtDesignPro-UI升级说明.md`）之上的第二轮视觉升级：
> **半调网点（Halftone / Ben-Day dots）+ 极光动效背景 + 纸感噪点 + 打字机 + 数字滚动 + 按钮涟漪/光泽/磁性**。
> 目标：脱离千篇一律的 CRUD 模板感，做出「专业级毕设」级别的艺术气息与动效品质，同时保持舒适、克制、可访问。
>
> 本轮升级**纯前端**，后端（Spring Boot WAR + MyBatis + PostgreSQL）零改动，所有数据仍来自真实接口。

## 1. 设计语言：半调艺术（Halftone Art）

灵感来自波普印刷的 Ben-Day 网点与现代 Editorial 排版：

| 元素 | 手法 | 出现位置 |
| --- | --- | --- |
| 半调网点 | `radial-gradient` 点阵 + `mask` 径向渐隐，由密到疏 | 登录左栏、欢迎横幅右上/左下角、印章 chip、全局页面底纹 |
| 极光光斑 | 3 个大尺寸模糊圆形光斑，16~24s 缓慢漂移（`aurora-drift`） | 登录左栏、看板欢迎横幅 |
| 纸感噪点 | 内联 SVG `feTurbulence`，opacity 0.04 + overlay 混合 | 登录左栏、欢迎横幅（印刷纸质感） |
| 虚线印章 | `flair-stamp`：1.5px 虚线圆角胶囊 + 6px 细点阵底 + 字距 1.5px | 「CAMPUS EXPRESS」logo 章、「LIVE」实时章、演示账号 chip |
| 渐变文字 | `flair-grad-text`：120° 蓝→紫渐变裁切文字 | 登录主标题第二行、看板问候语点缀 |
| 轨道圆环 | 双圈细描边圆环缓慢旋转，浮动信息卡绕排 | 登录左栏视觉中心 |

### 1.1 颜色精致微调（`src/styles/art-flair.css` 令牌）

主色从标准蓝向**矢车菊蓝**偏移一丝，配艺术紫/天青/薄荷/琥珀/珊瑚五色辅助：

```css
--flair-primary: #5b7cfa;   /* 矢车菊蓝（主色微调） */
--flair-violet:  #8b5cf6;   /* 艺术紫 */
--flair-sky:     #38bdf8;   /* 天青 */
--flair-mint:    #10d9b5;   /* 薄荷 */
--flair-amber:   #ffb020;   /* 琥珀 */
--flair-coral:   #fb7185;   /* 珊瑚 */
--flair-grad-hero: linear-gradient(120deg, #5b7cfa 0%, #7c6bfa 52%, #9b5cf6 100%);
--flair-ease: cubic-bezier(0.22, 1, 0.36, 1);  /* 全局统一缓动：快起慢收 */
```

暗色模式（`html.dark`）下全部令牌独立覆盖：网点透明度降低、极光光斑换深色相（#3d55c8 / #6d4fc0 / #0f7a66）且 opacity 0.55→0.22，保证暗色下「艺术但不刺眼」。

## 2. 全局动效层（art-flair.css，193 行）

| 类 / 机制 | 效果 |
| --- | --- |
| `.halftone` / `.halftone-fine` | 12px / 8px 间距半调点阵底纹 |
| `.halftone-corner` | ::before/::after 双角落点阵，mask 渐隐 + 8° 旋转 |
| `.grain` | SVG 噪点纸感 |
| `.aurora i` | 三光斑漂移，暗色自动降饱和降透明 |
| `.flair-in` + `--i:n` | 入场逐个浮现：opacity 0→1 + translateY 18px→0，每项延迟 n×70ms |
| `.el-button` 全局 | 按压缩放 0.96 回弹；primary 按钮渐变底 + 悬浮抬升 1px + 光晕阴影 + **光泽扫过**（skewX -20° 白色光带 hover 时 left -80%→130%） |
| `v-ripple` 指令 | 点击处生成圆形涟漪，scale 0→3 + 淡出，0.55s（`src/utils/ripple.js`） |
| `.art-card-hover` | 卡片悬浮 translateY(-4px) + 蓝色柔光阴影 |
| `.flair-bar > i` | 进度条宽度 1.1s 过渡 + ::after **流光**（bar-shine 2.4s 循环扫过） |
| `.typewriter-caret` | 3px 圆角光标，steps(1) 0.9s 闪烁 |
| `body` 底纹 | 22px 极淡半调纸纹，fixed 附着，暗色透明度降至 0.05 |

**可访问性**：`@media (prefers-reduced-motion: reduce)` 下关闭极光/入场/流光/光标动画，`.flair-in` 直接可见，按钮与卡片过渡归零——动效炫技不牺牲前庭敏感用户。

## 3. 新组件

### 3.1 `TypeWriter.vue` —— 打字机

- `texts` 支持字符串或数组；数组时**循环打字→停留→逐字删除→下一条**。
- 打字间隔 85ms + 0~40ms 随机抖动（模拟真人击键节奏），删除 38ms，停留 2200ms，均可配。
- `startDelay` 支持入场后延迟开打；`watch(texts)` 变化自动重播；卸载清理定时器。

### 3.2 `CountUp.vue` —— 数字滚动

- `requestAnimationFrame` + easeOutCubic（`1-(1-p)^3`），默认 1100ms，支持 `delay` 错峰。
- 千分位格式化 + `tabular-nums` 等宽数字（滚动不抖动）；value 变化从当前值续滚。

### 3.3 `v-ripple` 指令（utils/ripple.js）

- pointerdown 在点击坐标生成涟漪 span，动画结束自动移除；disabled 按钮不触发；static 定位元素自动补 relative。

## 4. 登录页重做（`views/Login.vue`，292 行）

**左栏 · 品牌艺术区**（≥1024px 显示）：
- 极光三光斑 + 纸感噪点 + 强半调点阵（mask 60% 渐隐）三层背景；
- 「CAMPUS EXPRESS」虚线印章 logo，`logo-breathe` 呼吸缩放；
- 双轨道圆环（r1/r2 反向缓旋）+ **3 张浮动信息卡**（📦 到站提醒 / 🤝 代取授权 / 📱 移动取件），入场浮现后接管 floatY 上下漂浮（相位错开 0/1.2/2.4s）；
- 主标题两行，第二行渐变文字；下方 **TypeWriter 循环标语**（取件提醒/代取授权/移动客户端等 4 句）；
- 底部版权灰 600 保证对比度。

**右栏 · 登录表单区**：
- 「欢迎回来 👋」wave 挥手动画；
- 登录按钮：**v-ripple 涟漪 + 磁性吸附**（mousemove 时按钮随指针偏移 dx/6、dy/4，离开回弹）+ 光泽扫过；
- 演示账号提示卡：`halftone-corner` 半调角 + 三枚角色 chip（admin / staff01 / 20230101）。

**响应式**：≤1024 隐藏左栏聚焦表单；≤640 单列紧凑布局。

**关键工程细节**：浮动卡片同时挂两个动画时，`flair-rise`（forwards/both）必须写在前面、`floatY`（infinite）写在后面接管 transform，否则入场透明度被无限动画覆盖导致卡片不显示——已修复并 QA 验证。
